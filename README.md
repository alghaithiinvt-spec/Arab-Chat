# Arab Chat — واجهة دردشة تفاعلية

واجهة كاملة تعمل بالكود الحقيقي: دردشة عشوائية، فيديو عشوائي، قائمة المحادثات، وحساب بقوائم المتابعين.

## الملفات
- `index.html` — الواجهة والمنطق (HTML + CSS + JavaScript بدون مكتبات).
- `backend.js` — طبقة بيانات محلية تحاكي قاعدة بيانات (localStorage). تُستبدل بخادم حقيقي لاحقًا.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع الملفات الثلاثة.
2. من Settings ← Pages اختر Branch: `main` والمجلد `/ (root)` ثم Save.
3. بعد دقيقة يظهر الرابط: `https://اسمك.github.io/اسم-المستودع/`

## تسجيل الدخول
يبدأ التطبيق بشاشة تسجيل الدخول: بريد وكلمة مرور، إنشاء حساب، استعادة كلمة المرور، وزر Google (تجريبي). الحسابات محفوظة في متصفحك فقط (localStorage) وكلمات المرور مشفّرة تشفيرًا بسيطًا للتجربة، فلا تستخدم كلمة مرور حقيقية. للإنتاج استعمل Firebase Authentication.

## التجربة
- افتح الصفحة في **تبويبين منفصلين** (لا نسخة مكررة). كل تبويب مستخدم مختلف: اضغط "ابدأ الدردشة" في الاثنين فيتصلان ببعض.
- إن بقيت وحدك 5 ثوانٍ، يتصل بك شريك تجريبي (سارة) ويرد على رسائلك.
- الفيديو يحتاج إذن الكاميرا، وتعمل المكالمة بين تبويبين على نفس الجهاز.

## الربط بخادم حقيقي (للمستخدمين الفعليين)
البيانات كلها تمر عبر `backend.js` بنفس واجهة Firebase Firestore (`collection / doc / get / set / update / delete / where / orderBy / limit / onSnapshot`). لجعل التطبيق يعمل بين أجهزة مختلفة:
1. أنشئ مشروعًا في Firebase وفعّل Firestore و Authentication (Google).
2. استبدل `backend.js` بنسخة تعيد `window.claude.use("db")` و `window.claude.use("user")` مبنية على Firebase.
3. للفيديو عبر الإنترنت أضف خادم TURN إلى إعدادات `RTCPeerConnection` داخل `index.html`.
